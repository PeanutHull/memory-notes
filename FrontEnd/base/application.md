### electron
1. 认识：开源的嵌入chromium + nodeJS的支持html+css+js进行桌面端app开发的平台
   - web技术体系，可搭配vue、react、next.js、three.js
   - 跨平台：macOS, Windows, Linux
     1. 使用社区支持的工具生成特定于平台的工具，如macOS的.dmg、windows的.msi、linux的.rpm(RPM Package Manager)
     1. 支持自定义应用程序窗口外观
     1. 支持应用商店分发
1. wiki
   - 基于OpenJS基金会
   - 底层包装了native API
